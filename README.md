# 離席中メモAR プロトタイプ

## ファイル構成
- `input.html` … メモ入力ページ（テンプレート選択・パスコード設定）
- `display.html` … AR表示ページ（マーカー認識→メモ表示／発信）
- `marker.mind` … 仮のプレースホルダー（要差し替え）

## 動作の仕組み（試作段階）
1. `input.html` で入力した内容は、ブラウザの `localStorage` に保存されます
2. `display.html` は同じ `localStorage` からデータを読み込んで表示します
3. そのため **今の状態では「同じスマホ・同じブラウザ」で両方開かないと動作しません**
   （＝1枚のプレートを試作する分にはこれで十分ですが、他人のスマホでは表示できません）
4. 複数人・複数デバイスで使えるようにするには、localStorageの代わりに
   FirebaseやSupabaseなどの外部データベースに差し替える必要があります

## 試す手順
1. `marker.mind` を、実際にコンパイルしたイラストのマーカーデータに差し替える
   （やり方は `marker.mind` の中のコメント参照）
2. この3ファイルを同じフォルダに置いたまま、HTTPS環境でホスティングする
   （カメラを使うため `file://` や `http://` では動きません。
    GitHub PagesやNetlifyの無料枠で問題なく動作します）
3. スマホで `input.html` を開き、内容とパスコード設定を保存
4. 同じスマホで `display.html` を開き、マーカー（イラスト）にカメラをかざす
5. パスコード設定に応じて、表示 or 発信時に入力を求められることを確認

## 既知の制限（試作版なので割り切っている部分）
- パスコードは平文でlocalStorageに保存しているだけなので、本番運用では非推奨
- 通知機能（Web Push）は未実装
- QRコードの発行・二次元コードからの導線は未実装（display.htmlのURLをQR化するだけでOK）
