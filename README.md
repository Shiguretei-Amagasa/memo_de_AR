# memodeAR プロトタイプ

## ファイル構成
```
index.html          … 入口ページ（入力／AR表示への案内）
input.html           … メモ入力画面
display.html          … AR表示画面
manifest.json         … ホーム画面追加（PWA）用設定
marker.mind           … 仮のマーカーデータ（要差し替え）
assets/style.css       … 共通デザイン（ロゴと同じ枠スタイル）
assets/img/            … ロゴ画像（メモ de AR _ logo.png）
assets/icons/          … ホーム画面アイコンの格納場所
```

## 「READMEのページが表示される」問題について
これはこのプロトタイプの不具合ではなく、フォルダの中に `index.html`（入口となるファイル）が
存在しなかったため、ホスティング先（GitHub Pagesなど）が代わりに `README.md` を
表示していたことが原因です。
今回 `index.html` を追加したので、フォルダのURLに直接アクセスすると
「メモを入力する／ARで確認する」の案内ページが表示されるようになります。

## 動作の仕組み（試作段階）
- `input.html` で「メモに設定」を押すと、内容が `localStorage` の `awayNoteActive` に保存されます
- `display.html` は同じ `localStorage` からこのデータを読み込んで表示します
- そのため **今の状態では「同じスマホ・同じブラウザ」で両方開かないと動作しません**
- 複数人・複数デバイスで使えるようにするには、localStorageの代わりに
  FirebaseやSupabaseなどの外部データベースに差し替える必要があります

## 入力画面の仕様（今回の変更）
- 内容：定型文（離席中／外出用／休み）／自由記述をプルダウンで切り替え
- パスコード：「表示時にパスコード」「発信時にパスコード」をそれぞれチェックボックスで個別に設定可能
- 連絡先：「電話連絡を有効にする」チェックで電話番号欄が表示
- 操作：メモを作成／メモを更新／メモを削除（履歴に対する操作）
- 「メモに設定」：入力中の内容をAR表示用としてセット（履歴とは別扱い）
- 履歴：直近5件まで保存し、タップで呼び出して編集・削除が可能

## AR画面の仕様（今回の変更）
- マーカー認識時、メッセージボックスを画面中央に大きく表示し、マーカー全体を覆うようにしています
  （3D空間に貼り付ける方式ではなく、認識中は固定表示するHUD方式に変更）
- 現在はシンプルな配色にしていますが、動作確認が取れたら「電脳っぽい」演出
  （発光・グリッチ風エフェクトなど）を追加できるよう、`assets/style.css` に
  `.frame-box.glow` という拡張用クラスを用意してあります

## 共通デザイン（ロゴの枠）について
いただいたロゴ画像（`assets/img/logo.png`）を参考に、`assets/style.css` の
`.frame-box` クラスとして枠デザインを再現しています。
- 左上・右下：直角の鋭いコーナー＋小さな四角アクセント
- 右上・左下：大きな半径の丸み
枠の太さ・丸みの半径は `--frame-width` / `--frame-radius` の2つの変数で
一括調整できるので、実物と見比べて微調整したい場合はこの数値を変更してください。

## ホーム画面アイコンについて
正式な `memodeAR_aicon.jpg` はまだアップロードされていないため、
暫定的にいただいたロゴ画像を `assets/icons/memodeAR_aicon.png` として配置し、
`manifest.json` から参照するようにしています。
正式なアイコン画像をいただき次第、同じ場所に差し替えます。

## 試す手順
1. `marker.mind` を実際のイラストからコンパイルしたデータに差し替える
2. （任意）正式な `memodeAR_aicon.jpg` が用意できたら `assets/icons/` に配置し、`manifest.json` の参照を更新する
3. フォルダごとHTTPS環境でホスティングする（GitHub Pages / Netlifyなど）
4. スマホで `input.html` を開き、内容を入力して「メモに設定」
5. 同じスマホで `display.html` を開き、マーカーにカメラをかざして表示を確認
